# 조작 버튼 그림 규격

이 폴더에 아래 이름의 PNG를 넣으면 글자 버튼 대신 그림 버튼이 나온다. 일곱 장이 모두 있어야 배치가 바둑판으로 바뀐다.

| 파일 | 동작 | 크기 |
|---|---|---|
| fwd.png | 전진 (W) | 256×256 |
| back.png | 후퇴 (S) | 256×256 |
| left.png | 좌회전 (A) | 256×256 |
| right.png | 우회전 (D) | 256×256 |
| sl.png | 왼쪽으로 옆걸음 (Q) | 256×256 |
| sr.png | 오른쪽으로 옆걸음 (E) | 256×256 |
| search.png | 조사 (F) | 256×512 안팎 (세로로 긴 버튼, 위아래가 옆 두 줄과 맞게 늘려 맞춘다) |

- 배경은 투명 PNG. 버튼 테두리와 그림자까지 그림 안에 그린다.
- 누를 때 어두워지고 살짝 눌리는 효과는 코드가 넣으니 한 장씩만 있으면 된다.
- 배치: 윗줄 좌회전·전진·우회전, 아랫줄 왼옆걸음·후퇴·오른옆걸음, 오른쪽에 조사가 두 줄 높이로.
