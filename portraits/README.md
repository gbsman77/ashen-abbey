# 파티 얼굴 그림 규격

| 파일 | 인물 |
|---|---|
| warrior.png | 로엔 (전사) |
| priest.png | 세라 (사제) |
| mage.png | 카일 (마법사) |

- 256×256 정사각형 PNG (더 커도 되고, 정사각형이 아니면 가운데를 잘라 쓴다).
- 얼굴이 가운데에 오게, 머리와 어깨 정도까지. 화면에는 56×56 크기로 작게 나오니 얼굴이 크게 차는 편이 좋다.
- 배경까지 채워서 그려도 되고 투명이어도 된다. 테두리는 코드가 그린다.
- 쓰러지면 코드가 흑백으로 어둡게 바꾸니 한 장씩만 있으면 된다.
- 그림이 없으면 직업 문양(⚔ ✚ ✦)이 대신 보인다.

## 다친 얼굴

- warrior_dmg.png, priest_dmg.png, mage_dmg.png (규격은 같다).
- 체력이 최대치의 3분의 1 이하로 떨어지면 이 그림으로 바뀐다. 없으면 평소 얼굴을 쓴다.
