# 화면 그림 규격 (ui/)

| 파일 | 자리 | 크기 | 화면에 보이는 크기 |
|---|---|---|---|
| title.png | 맨 위 제목 "잿빛 수도원" | 1200×240 (5:1) | 높이 64px (폰 48px), 너비는 비율대로 |
| save.png | SAVE 버튼 | 240×96 (5:2) | 높이 40px (폰 34px) |
| load.png | LOAD 버튼 | 240×96 | 같음 |
| new.png | NEW 버튼 | 240×96 | 같음 |
| frame.png | 던전 화면 테두리 | 1600×1000 (16:10) | 던전 화면 크기에 꼭 맞게 늘어남 |

- 모두 배경이 투명한 PNG.
- 제목은 글자와 장식만 그리고 나머지는 투명. 부제(DUNGEON PROTOTYPE · 3D)를 넣고 싶으면 그림 안에 같이 그린다.
- 세 버튼은 같은 크기로 그리고, 버튼 몸통이 그림 가장자리까지 꽉 차게 그린다. 누를 때 어두워지는 효과는 코드가 넣는다.
- frame.png는 가운데가 투명한 액자. 장식은 가장자리에서 안쪽으로 80px(위아래 60px) 안에 넣는다. 그보다 두꺼우면 던전이 가려진다.
- 방향 표시(동서남북)와 사건 창은 테두리가 있으면 그 안쪽으로 비켜 선다.
