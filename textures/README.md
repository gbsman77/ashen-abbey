# 벽·바닥 그림 넣는 곳

이 폴더에 아래 이름의 PNG를 넣으면 게임이 그 그림을 쓰고, 없으면 기본 질감을 그린다.

| 파일 이름 | 쓰이는 곳 | 크기 | 이어 붙이기 |
|---|---|---|---|
| wall.png | 모든 벽면 한 칸 (문틀, 계단 구멍 벽도) | 1024×1331 (가로:세로 = 10:13) | 좌우 끝이 이어져야 함 |
| floor.png | 바닥 한 칸, 계단 디딤판 | 1024×1024 | 상하좌우 모두 이어져야 함 |
| ceiling.png | 천장 한 칸 | 1024×1024 | 상하좌우 모두 이어져야 함 |
| door.png | 나무 문짝 앞면 | 768×1024 | 필요 없음 |

규격
- PNG, 배경 투명 필요 없음, 파일 하나 2MB 이하
- 정면에서 똑바로 본 평평한 그림 (원근·그림자·조명 없이). 빛과 어둠은 게임의 횃불이 입힌다
- 벽 한 칸은 폭 2m, 높이 2.6m 크기라서 벽돌 6~8줄 정도가 자연스럽다
- 바닥·천장 한 칸은 2m×2m. 판석 2×2 또는 3×3 정도
- 그림이 밝을수록 튀어나와 보이게 처리한다. 줄눈(틈)은 어둡게 그리면 입체감이 산다
