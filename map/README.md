# 지도 그림 규격 (map/)

있는 그림만 쓰고, 없는 것은 지금의 코드 그림으로 남는다. 모두 PNG.

| 파일 | 내용 | 크기 |
|---|---|---|
| bg.png | 지도 바탕 전체 (양피지, 낡은 종이, 석판 등). 아직 안 가 본 곳은 이 바탕이 보인다 | 512×512 |
| frame.png | 지도 테두리. 가운데는 투명, 장식은 가장자리 46px(9%) 안에 | 512×512 |
| floor.png | 가 본 길 한 칸 | 64×64 |
| wall.png | 가 본 벽 한 칸 | 64×64 |
| door.png | 문 표시 (길 칸 위에 겹친다, 배경 투명) | 64×64 |
| locked.png | 잠긴 문 표시 (배경 투명) | 64×64 |
| down.png | 내려가는 계단 표시 (배경 투명) | 64×64 |
| up.png | 올라가는 계단 표시 (배경 투명) | 64×64 |
| player.png | 내 위치 표시. 위쪽(북쪽)을 보고 있게 그리면 코드가 방향대로 돌린다 (배경 투명) | 64×64 |

- 지도는 화면에서 약 176×176 크기로 나오고, 한 칸은 지하 1층에서 약 10px, 지하 2층에서 약 18px로 작게 나온다. 칸 그림은 단순하고 대비가 큰 편이 잘 보인다.
- floor.png와 wall.png는 이웃 칸과 이어 붙으므로 가장자리에 굵은 테두리를 넣지 않는 편이 깔끔하다.
- player.png는 칸보다 30% 크게 그려진다.
