규격
- PNG, 배경 투명
- 정사각형 512×512 이상 (지금 그림은 512×512), 파일 하나 2MB 이하
- 정면(플레이어 쪽)을 보는 모습, 가로 가운데 정렬, 발이 아래쪽 가장자리 근처(여백 5% 정도), 위·좌우 여백도 5% 정도로 꽉 채우기
- 배경·바닥 그림자는 넣지 않기. 빛나는 적은 빛 번짐까지 그림에 포함
- 정사각형이 아니면 높이는 고정되고 가로만 비율대로 늘어난다
- 화면 속 크기는 engine.js 의 FOE_LOOK 에서 종류마다 정한다 (용이 가장 크다)

새 적을 추가하면 data.js monsters 의 sprite 이름과 같은 파일 이름을 쓰면 된다.
