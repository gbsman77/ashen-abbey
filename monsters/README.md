# 적 그림 넣는 곳

이 폴더에 아래 이름의 PNG를 넣으면 게임이 그 그림을 쓰고, 없으면 기본 그림을 그린다.

| 파일 이름 | 적 | 화면 속 크기 |
|---|---|---|
| rat.png | 거대 쥐 | 작음 (바닥에 붙어 있음) |
| skeleton.png | 해골 병사 | 사람 키 |
| wisp.png | 도깨비불 | 작음 (공중에 떠 있음) |
| guardian.png | 봉인의 수호자 (보스) | 매우 큼 |

규격
- PNG, 배경 투명
- 정사각형 1024×1024 권장 (최소 512×512), 파일 하나 2MB 이하
- 정면(플레이어 쪽)을 보는 모습, 가로 가운데 정렬, 발이 아래쪽 가장자리 근처(여백 5% 정도)
- 배경·바닥 그림자는 넣지 않기. 도깨비불처럼 빛나는 적은 빛 번짐까지 그림에 포함
- 정사각형이 아니면 높이는 고정되고 가로만 비율대로 늘어난다

새 적을 추가하면 data.js monsters 의 sprite 이름과 같은 파일 이름을 쓰면 된다.
